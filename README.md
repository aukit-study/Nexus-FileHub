# Nexus FileHub

เว็บจัดการไฟล์บนเซิร์ฟเวอร์ด้วย Node.js และ Express

## เริ่มใช้งาน

ต้องติดตั้ง Node.js LTS ก่อน จากนั้นใช้งานบน Windows ได้โดยดับเบิลคลิก `install.bat` เพื่อติดตั้งแพ็กเกจ แล้วดับเบิลคลิก `start.bat` เพื่อเปิดเซิร์ฟเวอร์ เมื่อเปิดใช้งานแล้วให้เปิด `http://localhost:3000` ในเบราว์เซอร์ และเปิดหน้าต่างเซิร์ฟเวอร์ค้างไว้ระหว่างใช้งาน กด `Ctrl+C` เพื่อหยุด

หรือเปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:

```bash
npm install
npm start
```

เปิด `http://localhost:3000` ในเบราว์เซอร์ กด `Ctrl+C` ใน Terminal เพื่อหยุดเซิร์ฟเวอร์

## ฟังก์ชัน

- อัปโหลดหลายไฟล์พร้อมกันด้วยการเลือกไฟล์หรือลากมาวาง พร้อมแสดงความคืบหน้า
- เลือกโฟลเดอร์ปลายทาง และสร้างโฟลเดอร์ใหม่ได้จากหน้าเว็บ
- ค้นหาและเรียงรายการตามชื่อ ขนาด หรือประเภท
- ดูสรุปจำนวนไฟล์ จำนวนโฟลเดอร์ และพื้นที่รวมที่ใช้
- แสดงตัวอย่างรูปภาพและวิดีโอ ดาวน์โหลด และลบไฟล์หรือโฟลเดอร์
- เมื่อมีชื่อไฟล์ซ้ำ ระบบจะเพิ่มเลขต่อท้ายเพื่อป้องกันการเขียนทับ

ไฟล์จะถูกจัดเก็บใน `uploads/` ภายในโปรเจกต์ ไฟล์ที่อยู่ในโฟลเดอร์นี้จะแสดงในคลังไฟล์

## หมายเหตุ

ค่าเริ่มต้นเปิดเซิร์ฟเวอร์ที่พอร์ต `3000` สามารถเปลี่ยนได้ด้วย environment variable `PORT` ตัวอย่างเช่น `PORT=4000 npm start`
